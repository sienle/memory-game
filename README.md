# Memory Game

Браузерная игра **Memory Game**, в которой необходимо найти все пары одинаковых карточек.

В игре 16 карточек, образующих 8 пар. Карточки перемешиваются при запуске игры и при начале новой игры.

## Возможности

* 16 карточек — 8 пар;
* случайное перемешивание карточек;
* подсчёт количества ходов;
* проверка найденных пар;
* задержка перед закрытием несовпавших карточек;
* кнопка **«Новая игра»**;
* модальное окно с результатом после завершения игры;
* таблица лидеров с 10 лучшими результатами;
* сохранение результатов в `localStorage`;
* сортировка результатов по количеству ходов и времени завершения;
* закрытие модальных окон кнопкой, кликом по overlay или клавишей `Escape`;


## Технологии

* HTML
* CSS / SCSS
* JavaScript
* Vite
* Bun


Проект реализован на чистом JavaScript без JavaScript-фреймворков и UI-библиотек.

## Локальный запуск

Для запуска проекта можно использовать **Node.js + npm** или **Bun**.

### 1. Клонирование репозитория

```bash
git clone https://github.com/sienle/memory-game.git
cd memory-game
git checkout memory-game
```

### 2. Установка зависимостей

**Node.js + npm:**

```bash
npm install
```

**Bun:**

```bash
bun install
```

### 3. Запуск сервера разработки

**Node.js + npm:**

```bash
npm run dev
```

**Bun:**

```bash
bun run dev
```

После запуска Vite выведет адрес локального сервера в терминале.

## Сборка проекта

**Node.js + npm:**

```bash
npm run build
npm run preview
```

**Bun:**

```bash
bun run build
bun run preview
```
